# UdyamAI Design System

## 1. Design Direction

UdyamAI follows a **Modern Rural FinTech** visual direction.

The design combines:
- Trust and financial clarity
- Rural accessibility
- Clean modern interfaces
- Generous whitespace
- Simple, purposeful visual elements

The interface should feel trustworthy, approachable, and easy to understand.

---

## 2. Color Tokens

### Primary Colors

| Token | Hex | Usage |
|---|---|---|
| Primary / Forest Green | `#176B4D` | Primary actions, navigation, key UI elements |
| Secondary / Sage | `#7BAE8A` | Secondary actions, supporting UI |
| Accent / Warm Amber | `#F2B84B` | Highlights, attention states, demo actions |
| Background / Warm Off-white | `#F7F6F1` | Main application background |
| Foreground / Charcoal | `#17221D` | Primary text |
| Danger / Muted Red | `#D95C5C` | Alerts, risk and error states |
